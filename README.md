## Daily Learning Flow

Each day:
1. Check WCB Learning page for tasks & check-in entry
2. Read relevant Handbook chapters
3. Plan minimum, recommended, and challenge paths
4. Create `daily/YYYY-MM-DD.md` with notes
5. Draft check-in content (I'll help)
6. Submit to WCB platform manually

## Handbook Feedback

Found a typo, unclear concept, or stale resource in the Handbook?

Create a note in `handbook-feedback/` with:
- Handbook page URL
- Issue description
- Suggested fix (if applicable)
- Context/source

## Getting Started

1. Read `profile.md` for learner background
2. Check `learning-plan.md` for your roadmap
3. See `daily/` for recent learning notes
4. Review `handbook-feedback/` to contribute back
