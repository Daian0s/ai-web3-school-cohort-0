## What was built

`experiments/first-agent/` — a uv-managed Python 3.12 project.

**Dependencies**: `web3` (blockchain RPC client) + `anthropic` (Claude API / tool calling)

**`main.py`**:
- `get_contract_info(address)` — makes a real RPC call to Sepolia
  (`eth_getCode` + `eth_getBalance`) and returns whether the address has deployed
  code and its ETH balance
- A tool schema describing this function to Claude
- `run_agent()` — the full loop: send the question → Claude decides to call the tool →
  the tool executes → result goes back to Claude → Claude gives the final answer

## Verified live

Ran `get_contract_info` directly (no AI layer, no API key needed) against the real
Sepolia WETH contract:
```
{'address': '0xfFf...', 'has_code': True, 'balance_eth': '217206.46...'}
```
Real RPC call, real blockchain response. The tool half is fully working. The AI
decision layer just needs an `ANTHROPIC_API_KEY` to run end-to-end.

## How to run it fully (whenever ready)
```bash
cd experiments/first-agent
uv run python main.py   # requires ANTHROPIC_API_KEY set in the environment
```
